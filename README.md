# AssistaMad – AI Health Assistant

AssistaMad is a smart health assistant and reminder system that helps users monitor basic health metrics and receive medical reminders. It integrates Arduino-based sensors with a user-friendly web and Android application.

## Features
- Health data monitoring using Arduino sensors
- AI-based assistant for basic health guidance
- Reminder system for medications and checkups
- Mobile application (Android) and web dashboard
- User and admin interfaces

## Tech Stack
- **Hardware**: Arduino, sensors
- **Languages**: Python, PHP, SQL, JavaScript, XML, Kotlin
- **Frontend**: HTML, CSS, Bootstrap
- **Mobile**: Android (XML + Kotlin)
- **Backend**: PHP + SQL

## Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone https://github.com/muhammaddaniyalcs/AssistaMad-AI-Health-Assistant.git

2. **Web App**

- Move web/ to htdocs/ (XAMPP).

- Import assitamad.sql in phpMyAdmin.

- Access via http://localhost/web/.

3. **Android App**

- Open android/ in Android Studio.

- Run on device/emulator.

- Update API URLs if required.

4. **Arduino**

- Open .ino file from arduino/ folder in Arduino IDE.

- Connect sensors and upload to board.
